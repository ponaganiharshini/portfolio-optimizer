How the algorithm works

  1. Sort projects by return per cost (best value first).
  2. Branch: for each project make two choices, take it or skip it. This builds a decision tree.
  3. Bound: for each branch, compute the best return it could possibly reach (fill the budget, allowing a fraction of the last project).
  4. Prune: if that bound cannot beat the best portfolio already found, throw the whole branch away. If a branch goes over budget, drop it too.
  5. The best portfolio left at the end is optimal, and it is double-checked with Dynamic Programming.

Brute force checks all 2ⁿ combinations. Branch & Bound reaches the same answer while skipping most of them.
